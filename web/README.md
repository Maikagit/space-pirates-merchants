# Space Pirates and Merchants 3D (Prototype)

Cette version web utilise **Three.js** pour proposer une démo 3D en vue
« troisième personne ». Le vaisseau peut se déplacer sur les trois axes et la
caméra reste orientée vers l'avant du vaisseau.

## Lancer la démo

Ouvrez `index.html` dans un navigateur compatible WebGL.

## Contrôles

- **W** : Accélérer
- **S** : Ralentir
- **Flèches ou A/D** : Rotation horizontale
- **Flèches Haut/Bas** : Tangage
- **Q/E** : Roulis

Cette démo comprend quelques planètes, un portail et des lueurs de base pour illustrer l'univers.
